# AI Data Analyst — Text-to-SQL Assistant

Upload any SQLite database and ask questions in plain English.
AI automatically generates and runs the SQL query for you.

##  Tech Stack
- Python + Streamlit
- Google Gemini 2.5 Flash
- SQLite + Pandas

##  How to Run
1. pip install -r requirements.txt
2. streamlit run app.py
3. Enter your Gemini API key in sidebar
4. Upload your SQLite database
5. Ask your question!

##  Features
- Upload ANY SQLite database
- AI reads your schema automatically
- Zero SQL knowledge needed
- Instant results as a table
